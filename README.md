# puzzleGame

This project is a specialized puzzle game developed as a school project using **C#**. The core of the application focuses on computational geometry and algorithmic optimization to achieve the best "regularity" on a computer-generated puzzle board.

## Project Overview
The game is built on a puzzle system where the board is generated through complex computer calculations. The main objective for the player (or the algorithm) is to interact with the puzzle elements to find and maintain the **optimal regularity score**. 

### Key Features
* **Algorithmic Generation:** Puzzle layouts are created using specific mathematical models.
* **Regularity Calculation:** Includes a custom engine to calculate and track the regularity of the puzzle state in real-time.
* **Optimization Gameplay:** Players must make strategic moves to reach the highest consistency and structural order as defined by the project requirements.

### Technologies Used
* **Language:** C#
* **Framework:** .NET (Buraya kullandığınız versiyonu yazabilirsiniz, örn: .NET 6.0 / Windows Forms / WPF)
* **Concept:** Computational calculation and regularity optimization.
